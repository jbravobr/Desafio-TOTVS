# Desafio TOTVS — To Brasil Backend

> Desafio técnico para desenvolvimento backend em .NET, organizado com solução e arquivos de Docker Compose.

## Organização

- `src/` — código-fonte principal.

Solução: [`Desafio-TOTOVS.sln`](Desafio-TOTOVS.sln).

## Tecnologias

C# e .NET; o projeto web utiliza ASP.NET Core.

## Como abrir

Abra [`Desafio-TOTOVS.sln`](Desafio-TOTOVS.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
